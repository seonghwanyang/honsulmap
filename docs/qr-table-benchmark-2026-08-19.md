# 혼술바 테이블 서비스 벤치마크 & 혼술맵 적용 설계

2026-08-19 · 필드 리서치: 야화 합정/홍대 · 우우 홍대 · 문래한잔 (실방문 캡처 31p, `honsulbar_menu_document.pdf`)

## 0. 요약

세 가게가 각각 시장의 3개 층을 대표한다:

| | 야화 | 우우 | 문래한잔 |
|---|---|---|---|
| 방식 | **태그히어** (범용 F&B SaaS) | **자체 개발** (Next.js+Vercel) | **토스플레이스** (포스 번들) |
| 주문 | QR 주문 → 후불 카운터 결제 | QR 주문 → 태블릿 수신 → 후불 | 토스 테이블오더 (포스 자동연동) |
| 정체성 | 도구 (메뉴판+포인트) | **가게 컨셉 그 자체** (Social OS) | 인프라 |

**핵심 발견 3개:**
1. **주문의 포스 전달은 3사 3색, 결제는 방문 3곳 모두 후불 카운터.** 태그히어는 OK POS 등 **10개 포스사와 공식 계약해 주문이 주방 주문서로 자동 전달**되고(직원 재입력 불필요), 토스는 자사 포스라 당연히 자동, 우우(자체 제작)만 태블릿 수신 후 포스 수동 이기입. 결제는 세 매장 모두 후불 카운터를 선택했지만 태그히어 제품 자체는 카카오·네이버·토스페이 선결제도 지원(매장별 설정). → 소형 혼술바 기준 "주문 접수만 되면 충분, 결제는 카운터"가 유효하되, 포스 자동전달은 태그히어의 실질 우위임을 인지할 것.
2. **태그히어가 우리 구상과 가장 겹치는 직접 경쟁자** (QR+포인트 네트워크+가게 유틸). 단, 수요 채널(지도·앱·커뮤니티)이 없다 — 손님을 못 데려온다. 우리의 해자는 그대로 유효.
3. **우우는 "잘되는 자체사이트"의 실체**이자 혼술 특화 기능의 보물창고 (퀘스트·좌석 소셜·술게임·라이브 상태). 수제작이라 확산 불가 → **"우우를 SaaS로"가 태그히어가 못 따라오는 혼술 특화 차별화.**

포지셔닝 한 줄: **태그히어의 테이블 기능 × 우우의 소셜 모듈 × 혼술맵만 있는 수요 채널(지도→방문→단골 풀루프).**

## 1. 상세 분석

### 1-1. 야화 × 태그히어 (tag-here.com)

- 운영사: **(주)티엠알파운더스** (성수 SK V1, 사업자 492-88-02374). 주문웹 `tag-here.com`, CRM·채팅 `taghere-crm-web-*.onrender.com` (Render 호스팅).
- 체급 (2026 언론 보도): 2023-10 출시 → **2026 1분기 흑자전환, 연간 주문 거래액 2,000억+, 누적 이용자 1,000만+**, CRM 출시 3개월 만에 고객 데이터 20만 명(월 6만 적재), 하이트진로 전략투자(NFC 테이블오더), 프차 본사 단위 계약 확대 중. 생각보다 큰 상대.
- **포스 연동: 있음.** OK POS·KIS·나이스·union pos·easy pos 등 **10개 포스사와 공식 계약** — QR 주문이 포스를 거쳐 **주방 주문서로 자동 출력**, 직원 재입력 불필요. 기타 포스는 상담 연동. (이게 태그히어의 진입장벽 투자 — 우리가 정면으로 따라가면 안 되는 영역)
- 상품 조건: **14일 무료체험, 무약정·해지 위약금 없음**, 기존 서브포스·프린터 호환(추가 기기 구매 불필요), NFC 태그(무전원)+QR 스탠드(커스텀 디자인), 간편결제 3사 선결제 옵션, AI 다국어(영중일). 가격은 비공개(상담) — 파일럿 영업 전 무료체험 계정 만들어 견적 확인 권장.
- 손님 플로우: 테이블 QR(JWT 토큰 URL) → **성별 선택** → 테이블번호 입력 → 메뉴/장바구니 → 주문 → **주문 완료 화면에서 포인트 10% 적립 유도 + "전국 매장 혜택 수신 동의" 필수 체크**.
- 기능 목록 (캡처 실측):
  - 메뉴판 + 장바구니 + 주문 (후불: "모든 주문은 후불 결제, 퇴장 전 카운터에서 한 번에")
  - **포인트 네트워크**: 주문액 10% 적립, 전국 태그히어 매장 공통 — CRM/재방문 장치이자 마케팅DB 수집기
  - **가게별 익명 채팅방** (야화 채팅방)
  - **₩0 아이템 패턴**: 직원 호출 ₩0, "사장님 여기 빌런있어요! ₩0" — 호출·신고·요청을 전부 "메뉴 주문"으로 처리해 별도 UI 없이 주문 파이프 하나로 통일. 영리함.
  - 매장 유틸: 와이파이 비번 원탭 복사, 화장실 위치, 매장 안내사항
  - **네이버 영수증 리뷰 이벤트** (리뷰 작성 시 뽑기 1회권) — 리뷰 유도를 사행성 재미로
  - 외부 제휴: 세븐일레븐 5,000원 쿠폰
  - PWA 설치 유도, 다국어 버튼
- 약점: 범용 F&B라 혼술 맥락 없음. 수요 채널 없음. 가게 입장에선 "손님이 온 다음"만 도와줌.
- 시사점: 야화는 자체앱이 아니라 SaaS 구독자였다 → **소형 프차도 이런 도구에 돈을 낸다는 지불의사 증거**이자, 태그히어 고객을 뺏어올 수도 있다는 뜻.

### 1-2. 우우 (홍대 혼술바, woowoo-social-os.vercel.app)

- 자체 개발 (Next.js + Vercel, 웹푸시 사용). "혼자 와도 외롭지 않은 공간" — 소셜 혼술바 컨셉과 앱이 일체화.
- **체크인**: 좌석번호 + 휴대폰 뒤 4자리만. "개인정보 미저장, 영업 종료 후 자동 만료" — 가입 마찰 최소화 설계.
- **프로필**: 나이대·성별(항상 공개)·MBTI(선택)·오늘의 목적("편하게 대화하고 싶어요"~"조용히 마시고 싶어요")·선호 분위기·TMI 한 줄·선호 술·공개 토글.
- **실시간 좌석맵**: 구역(내측 1-16/창측 17-31/문측 32-34) + 좌석별 성별 표시 + 빈자리/사용중/내자리 + 버퍼석(자리이동 대기). 다른 손님 프로필 열람 가능.
- **좌석 로테이션**: 신청제(2명 이상 시 성사), 직원 안내 시 진행, 나이대·선호·분위기 고려 매칭.
- **오늘의 퀘스트** (5개/일, HIDDEN 포함): "위스키 3잔 → 하프샷 증정", "MBTI 같은 사람 찾기 → 레몬드랍 슈터", "시그니처 3잔 → 1잔 무료", "칵테일 5종 도장깨기". 달성 시 탭 → **직원에게 알림 전송**. 객단가+소셜을 동시에 올리는 게임화.
- **술게임 도감**: 메두사·양세찬·빙고·랭킹·폭탄돌리기 등 — 인원수·태그(입문/텐션업/처음 만난 사람)·벌칙 명기. 어색함 깨기용 콘텐츠.
- **이벤트 메뉴**: 꽝없는 뽑기 ₩8,000 (1등 모엣샹동 바틀), 직원에게 추천받기 ₩0, **"그냥 이유없이 한 잔 드리고 싶어요"** (익명 선물 — 플러팅 아님 명시), 불편 신고 ₩0.
- **홈 라이브 상태**: "오늘 우우는 ⚡빠르게 자리 차는 중!!" / "☕ 도란도란 시작하는 중" — 실시간 가게 무드 방송. 우리가 논의한 "지금 자리 있어요"가 실전에서 돌아가는 증거.
- **트러스트&세이프티**: 과한 플러팅·외모 평가·비교 발언 등 "경고 없이 퇴장" 목록, 20분 자리비움 퇴장. 소셜 기능엔 규칙이 필수라는 교훈.
- 운영 뒷단(사용자 메모): "주문 오면 태블릿으로 전송 후 포스기 확인" — 포스 연동 없음, 수동 이기입.
- 약점: 이 가게 전용 수제작. 템플릿화·확산 불가. 그래서 기회.

### 1-3. 문래한잔 × 토스플레이스

- `toss-order.tossplace.com/table/{tableId}/menu?tid={sessionId}` — 테이블 세션 기반 (세션 만료 시 404, 실측 확인).
- 토스 포스에 번들된 테이블오더. 별도 개발 없이 포스 자동 연동 — 이게 인프라층의 힘.
- 기조사 사항: 포스 SW 무료, 하드웨어 월 9,900원, **Open API로 외부 주문을 포스에 주입 가능** (티오더가 실제 연동 사례).
- 시사점: 경쟁하지 말고 올라탈 것. 토스포스 쓰는 가게엔 v3에서 Open API로 우리 주문을 포스에 넣어주면 됨.

## 2. 시장 구조와 혼술맵의 자리

```
[인프라]   토스플레이스 — 포스·결제·하드웨어. 싸우면 짐. 연동 대상.
[범용SaaS] 태그히어 — QR주문+포인트+유틸. 직접 경쟁. 단 수요채널 없음.
[가게수제] 우우 — 혼술 소셜 OS. 확산 불가. 기능 레퍼런스.
[혼술맵]   ??? → "혼술 특화 SaaS + 수요 채널"의 교집합. 비어 있음.
```

태그히어 대비 우리가 이기는 지점:

| | 태그히어 | 혼술맵 |
|---|---|---|
| 손님 데려오기 | ✗ | ✅ 지도·앱·커뮤니티 (DAU ~350, 오가닉 ~100) |
| 혼술 특화 (소셜·퀘스트·술게임) | ✗ (범용) | ✅ 우우 모듈 SaaS화 |
| 가게 콘텐츠 자동화 | ✗ | ✅ IG 스토리 스크레이핑 (이미 운영 중) |
| 방문 전~후 풀루프 | 방문 후만 | ✅ 발견→방문→테이블→단골→재방문 |
| 포인트 네트워크 | 전국 태그히어 매장 | 혼술맵 계정 연동 시 전국 혼술바 스탬프 (앱이 이미 있어 더 자연스러움) |
| **포스 연동 (걔네가 이기는 곳)** | ✅ 10개사 공식 계약, 주방 자동 출력 | ✗ v1 알림형으로 우회 (8~20석 바는 주방 분리 없어 충분 — 우우 실증) → v3 토스 Open API |

## 3. 기능 설계

### 3-1. 손님 버전 — 스팟 페이지 "테이블 모드"

진입: 테이블 QR → `/spot/{slug}?table=N` (기존 스팟 페이지에 테이블 컨텍스트).

**기본 (모든 가게):**
- 메뉴판 (시드: 이미 수집된 `naver_menus` → 사장님 편집으로 확정)
- 오늘의 혜택 + 스탬프 적립 (기존 benefit/RedeemSheet 확장)
- 직원 호출 (태그히어의 ₩0 아이템 패턴 차용)
- 와이파이 비번 복사·화장실 안내 (스팟 메타)
- 가게 채팅방 (이미 있음 — 태그히어 익명 채팅방과 동일 포지션)
- 네이버 리뷰 이벤트 버튼 (리뷰 → 뽑기/혜택)

**옵션 A — 주문 (테이블석 가게):**
- 장바구니 → 주문 → 사장님 수신 (실시간 보드 + 알림톡 이중화) → 후불 카운터 결제 (시장 표준)
- 요청사항 입력란 ("얼음 적게")

**옵션 B — 소셜 모듈 (소셜 컨셉 가게만):**
- 체크인 (닉네임+선택 프로필, 영업 종료 자동 만료 — 우우 방식)
- 좌석맵 + "말 걸어도 돼요" 상태
- 오늘의 퀘스트 (사장님이 템플릿에서 선택)
- 술게임 도감 (**전 가게 공통 콘텐츠로 우리가 1회 제작** — 모든 가게가 재사용)
- 익명 한 잔 선물
- 트러스트&세이프티 규칙 기본 내장 (우우 것 벤치마크)

**혼술맵 연결 (태그히어가 못 하는 것):**
- 테이블 모드 진입 = 실방문 신호 → 지도에 "지금 살아있는 가게" 표시
- 혼술맵 계정 연동 시 스탬프 전국 통합 + 찜한 가게 소식 푸시
- 방문 후 리뷰 → 커뮤니티 피드 순환

### 3-2. 사장님 버전 — partner 대시보드 확장

- **메뉴 관리**: naver_menus 가져오기 + 품절/오늘의 안주 토글 + 가격 수정
- **주문/호출 접수 보드**: 실시간 (Supabase Realtime — 채팅 스택 재활용) + 소리 + 알림톡 백업 (1분 미확인 시) + 감열 프린터 옵션 (기기 실비)
- **이벤트/퀘스트 템플릿**: "혼자 왔어요 첫잔", "스탬프 3방문 서비스", "요일 이벤트", 퀘스트 3종 — 고르면 포스터 이미지+QR 자동 생성
- **원터치 운영**: 임시휴무·브레이크·"자리 있어요" 라이브 상태 (우우 홈 배지의 사장님 버전, 지도 연동)
- **주간 리포트 카톡**: 스캔·주문·리딤·스탬프·조회 (admin view-stats 재활용)

### 3-3. 본사 버전 (소형 프차, v2+)

- 지점 비교 대시보드 (조회·스캔·리딤 랭킹)
- 메뉴 마스터 일괄 배포 (지점은 로컬 안주만 추가)
- 지점 SNS 활동 리포트 (스토리 수집 데이터 이미 있음 — 사실상 공짜)
- 브랜드관 + 가맹 문의 리드 수집

### 3-4. 안 만드는 것

- 결제 (후불 표준 실증 — PG·정산 리스크 회피, v2 금액권 선판매만 별도 검토)
- 포스 연동 v1 (토스 Open API는 v3, 토스포스 가게 확보 후)
- 예약 시스템 (수요 미검증)

## 4. 로드맵

| 단계 | 기간 | 내용 | 검증 목표 |
|---|---|---|---|
| **v1** | 2~3주 | 테이블 모드 기본형 (메뉴+혜택+스탬프+호출) + 사장님 메뉴/휴무/리포트 + QR 스탠드 인쇄·배송 | 파일럿 3곳, 스캔·리딤 실발생 |
| **v1.5** | +2주 | 알림형 주문 (보드+알림톡), 이벤트 템플릿 5종, 라이브 상태→지도 연동 | 주문 사용률, "자리 있어요" 클릭 |
| **v2** | 이후 | 소셜 모듈 (체크인·좌석·퀘스트·술게임), 전국 스탬프 네트워크, 금액권 선판매, 프차 패키지 | 유료 전환 (셋업비→구독) |
| **v3** | 스케일 | 토스플레이스 Open API 주문 주입, 본사 대시보드 고도화 | 프차 본사 1곳 계약 |

12주 유료 검증 게이트(기존 합의)와 동일 트랙: v1 무료 3곳 → 숫자 확보 → 셋업비 3~5만 유료 요청 → 3곳 중 1곳+신규 2곳 전환 시 지속.
