## 2. 로테이션 (2026-07-14 확정)

- **방식**: 캐러셀식 상시 이동이 아니라 **"정지 → 짧은 슬라이드" 반복**
- **정지 노출**: `AD_ROTATE_HOLD_MS = 4000` (4초)
- **슬라이드 전환**: `AD_ROTATE_SLIDE_MS = 250` (0.25초, 왼쪽으로 밀리며 다음 배너 진입)
  - 형 제안은 0.1초였는데 뚝 끊겨 보이는 경계라 모바일 표준(200~300ms)의 250ms를 기본값으로. 상수 하나만 바꾸면 조정됨
- **시작 순서**: 접속(마운트)마다 랜덤 → 광고주 간 첫 노출 균등
- **순환**: 마지막 배너 → 첫 배너로 무한 루프 (클론 트릭, 역방향 점프 없음)
- 배너가 1개뿐이면 로테이션 없이 고정 노출

## 3. 크리에이티브 규격

- **광고주 제출 가이드**: 1500×240 (`Business_advertisement/banner_guide_1500x240.png`) — 중앙 60% 세이프존, 상하 여백 금지
- **가이드와 다른 원고가 오면** (실사례 2건):
  - 포스터형(지문인식): CSS 세로 크롭 — `aspectRatio` + `objectPosition`으로 타이틀 밴드만 노출
  - 여백 있는 배너형(엮은이): PIL로 여백 제거 → 콘텐츠 축소 → **원본 배경색 1206×190 캔버스 재조판** 후 파일 자체를 규격화
- 파일 위치: `public/ads/*.jpg` (원본 보관: `Business_advertisement/`)
