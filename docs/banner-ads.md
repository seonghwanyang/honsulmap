## 2. 로테이션 (2026-07-14 확정 · 업계 조사 반영)

- **방식**: 캐러셀식 상시 이동이 아니라 **"정지 → 짧은 슬라이드" 반복**
- **전환 형태**: **push 슬라이드** — 이전 배너가 왼쪽으로 밀려나가는 동안 다음 배너가 이어 붙어 들어옴 (전환 내내 두 광고 다 보임). **중간 회색/빈 프레임 없음** — 빈 프레임은 로딩 실패처럼 보이고 광고 노출 시간만 깎아서 쓰는 곳이 없음. 캐러셀 UX 가이드도 cross-fade보다 수평 슬라이드 권장
- **정지 노출**: `AD_ROTATE_HOLD_MS = 5000` (5초)
  - 근거: UX/접근성 가이드(W3C·NN/g 계열)는 슬라이드당 **최소 5~7초**(읽을 시간), 국내 커머스 앱 롤링배너 실측은 3~5초대 → 두 기준이 겹치는 5초 채택. 5초 초과 회전엔 일시정지 버튼 권장이라 5초가 컨트롤 없이 쓸 수 있는 스윗스팟
- **슬라이드 전환**: `AD_ROTATE_SLIDE_MS = 400` (업계 300~400ms 구간)
- **가속도(이징)**: `cubic-bezier(0.05, 0.7, 0.1, 1)` — Material 3 "emphasized decelerate". **최고 속도로 출발해 끝에서 부드럽게 감속**하는 커브. CSS 기본 `ease`는 출발이 느려 짧은 슬라이드에서 뚝 끊겨 보임 (1차 구현이 안 매끄러웠던 원인)
- **시작 순서**: 접속(마운트)마다 랜덤 → 광고주 간 첫 노출 균등
- **순환**: 마지막 배너 → 첫 배너로 무한 루프 (클론 트릭, 역방향 점프 없음)
- 백그라운드 탭에선 진행 정지 (`document.hidden` 가드), 배너 1개뿐이면 고정 노출
- GPU 합성: 트랙에 `will-change: transform`
